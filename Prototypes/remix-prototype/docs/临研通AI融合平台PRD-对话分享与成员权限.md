## 一、需求背景与目标

### 1.1 背景

医研千问项目知识库已实现基础功能：新建项目、上传文档、基于文档进行问答。当前系统页面结构如下：
- 左侧：AI 工作台 / 医研千问导航
- 中间：对话区域（问答内容展示）
- 右侧：项目知识库（文档列表，含向量化状态标识）

### 1.2 目标

1. 支持对话分享，分享后被分享者可查看该条对话、继续提问、查看项目知识库内容
2. 实现项目成员权限管理，区分创建者与受邀成员的操作权限
3. 新增群聊模块，支持单聊和多人群聊，分享时可推送给项目成员、群聊或联系人

## 三、功能需求

### 3.1 对话分享

#### 3.1.1 分享入口

**页面位置**：对话页面

**触发条件**：用户点击对话区域的"分享"按钮

**页面表现**：弹出分享配置弹窗

#### 3.1.2 分享配置弹窗

**展示内容**：
- 第一部分：知识库同步选项
  - "分享（含知识库）" — 同步分享当前项目知识库
  - "仅分享对话" — 仅分享当前对话，不分享知识库
- 第二部分：分享链接（复制链接按钮）
- 第三部分：推送至群聊或协同成员
  - 搜索框：搜索群聊、姓名、角色职责
  - 推送目标分类展示：
    - **当前项目成员**：动态加载该项目下的成员列表
    - **我的群聊**：用户参与的群聊列表（显示群名称和成员数）
    - **联系人**：单聊联系人列表
  - 每个目标支持：勾选批量发送 / 单独点击"发送"按钮
- 底部按钮："取消""确认分享"

**规则**：
- 项目成员、群聊、联系人三类目标可同时选择
- 发送后目标状态变为"已发送"
- 推送通过临研通IM自动发送
- **知识库同步差异**：
  - 推送给**项目成员**：知识库内容实时同步，原项目新增/删除文档后，被分享者可见最新状态
  - 推送给**群聊/联系人**：知识库内容为分享时点的快照，后续原项目知识库更新不影响已分享内容

#### 3.1.3 分享链接生成

**规则**：
- 生成公开分享链接，无需密码
- 无有效期限制
- 分享链接可被任何人访问

**页面表现**：
- 生成链接后展示链接地址
- 提供"复制链接"按钮
- 提示"链接已复制"

#### 3.1.4 被分享者查看对话

**页面表现**：
- 通过分享链接进入后，展示被分享的那一条对话的完整内容（用户提问 + AI 回答）
- 页面布局与原文一致
- 页面顶部展示分享人信息
- 展示项目知识库区域（仅当分享时选择"同步知识库"）

**规则**：
- 仅展示被分享的那一条对话，不可查看该项目的其他对话历史

#### 3.1.5 被分享者继续提问

**页面表现**：
- 对话区域底部保留输入框，可输入问题并发送
- 提问后，AI 基于原项目知识库进行回答
- 新产生的问答追加在原文下方

**规则**：
- 被分享者可在该对话中持续提问
- 回答基于原项目知识库内容
- 新产生的问答仅在分享链接中可见，原分享者不可见（分享链接为独立副本）
- 新产生的对话归属于原项目

#### 3.1.6 被分享者查看知识库

**展示条件**：分享时选择"同步分享知识库文件"

**页面表现**：
- 页面右侧展示项目知识库文档列表
- 文档列表为只读状态，不展示"上传""删除"等操作按钮
- 文档列表内容实时同步原项目的知识库更新

**规则**：
- 仅可查看，不可上传、删除、编辑
- 知识库内容为实时同步，原项目新增/删除文档后，被分享者可见最新状态

#### 3.1.7 再次分享

**规则**：
- 被分享者可将当前对话再次分享给其他人
- 再次分享时，同样弹出"是否同步分享知识库文件"配置弹窗
- 分享链路无次数限制

### 3.2 项目成员管理

#### 3.2.1 邀请成员入口

**页面位置**：项目顶部栏"成员管理"按钮

**触发条件**：创建者点击"邀请成员"按钮

**页面表现**：
- 弹出邀请配置弹窗
- 输入框：被邀请用户的手机号
- 按钮："发送邀请""取消"

**规则**：
- 被邀请者不可拒绝邀请，接受后直接成为项目成员
- 被邀请者收到IM通知，点击后直接加入项目

#### 3.2.2 成员列表展示

**页面位置**：项目管理页面 / 项目设置区域

**展示内容**：
- 成员列表，包含以下字段：
  - 用户头像/昵称
  - 角色（创建者 / 成员）
  - 加入时间
- 创建者所在行展示操作按钮："移除"
- 成员所在行无操作按钮

#### 3.2.3 移除成员

**触发条件**：创建者点击成员行"移除"按钮

**页面表现**：
- 弹出二次确认弹窗："确认移除该成员？移除后该用户将无法访问该项目"
- 按钮："确认移除""取消"

**规则**：
- 移除后，该用户失去该项目所有访问权限
- 该用户已创建的对话属于个人，不受影响

### 3.3 即时通讯（群聊模块）

#### 3.3.1 模块入口

**页面位置**：页面右侧悬浮按钮（已存在）

**展示内容**：
- 右侧悬浮群聊图标（消息气泡样式）
- 点击后弹出群聊弹窗（非全屏页面）

#### 3.3.2 消息中心页面

**页面结构**：
- 左侧：会话列表（单聊 + 群聊）
- 右侧：聊天内容区域

**会话列表展示**：
- 按最近消息时间倒序排列
- 每个会话展示：头像/群头像、名称、最后一条消息预览、时间
- 群聊会话显示群名称和成员数（如"项目沟通群（8人）"）
- 单聊会话显示对方昵称

#### 3.3.3 创建群聊

**触发条件**：用户点击"新建群聊"按钮

**页面表现**：
- 弹出联系人选择弹窗
- 搜索/勾选要邀请的联系人
- 输入群聊名称
- 按钮："创建""取消"

**规则**：
- 创建者自动成为群主
- 群主可添加/移除群成员
- 群聊独立于项目，不绑定任何项目
- 群聊不支持知识库共享

#### 3.3.4 群聊成员管理

**触发条件**：群主/管理员点击群聊设置

**功能**：
- 查看群成员列表
- 添加成员：从联系人中选择
- 移除成员：点击成员行"移除"按钮
- 群主可转让群主身份

**规则**：
- 仅群主可移除成员
- 移除后该成员不再接收群消息
- 群主退出时，需先转让群主身份

#### 3.3.5 单聊

**触发条件**：从会话列表点击单聊会话，或从联系人发起单聊

**页面表现**：
- 右侧聊天区域显示对话历史
- 底部输入框支持文字输入
- 支持发送文字消息

#### 3.3.6 消息收发

**规则**：
- 支持文字消息收发
- 消息按时间顺序展示
- 新消息实时推送
- 群聊不支持知识库共享（与项目知识库隔离）

| R28 | 项目成员与群聊为独立概念，不自动关联 |

## 五、异常处理

| 场景 | 处理方式 |
|------|----------|
| 无权限上传文档 | 隐藏/禁用上传按钮，或提示"仅创建者可上传" |
| 无权限删除文档 | 隐藏/禁用删除按钮，或提示"仅创建者可删除" |
| 项目被删除 | 分享链接失效，提示"该项目已不存在" |
| 成员被移除 | 该用户失去项目访问权限，其个人对话不受影响 |
| 群主未转让身份直接退出 | 提示"请先转让群主身份"，阻止退出 |
| 非群主尝试移除成员 | 隐藏/禁用移除按钮，或提示"仅群主可移除成员" |
| 群成员被移除 | 该成员不再接收群消息，会话列表移除该群 |
| 创建者尝试退出项目 | 提示"创建者不可退出项目"，阻止退出 |
