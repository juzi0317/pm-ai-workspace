# 阿里云 ECS 部署指南

## 快速开始

### 1. 准备阿里云 ECS 实例
- 选择 **Node.js 应用** 或 **通用 Linux** 系统镜像
- 建议配置：2核4GB（LLM 调用需要一定内存）
- 开放安全组端口：**3000**

### 2. 上传项目文件
将 `deploy` 文件夹上传到服务器：
```bash
scp -r deploy/* root@你的服务器IP:/home/app/
```

### 3. 安装依赖
```bash
cd /home/app
npm install
```

### 4. 配置环境变量
创建 `.env` 文件：
```bash
echo "DASHSCOPE_API_KEY=sk-a0e4986a69574ae3a05bd019a26513c4" > .env
echo "NODE_ENV=production" >> .env
echo "PORT=3000" >> .env
```

### 5. 启动服务
```bash
npm start
```

服务将在 `http://你的服务器IP:3000` 启动

### 6. 使用 PM2 保持运行（推荐）
```bash
npm install -g pm2
pm2 start server.cjs --name "ai-prototype"
pm2 save
pm2 startup  # 设置开机自启
```

## 访问地址
- 前端页面：`http://你的服务器IP:3000`
- API 端点：`http://你的服务器IP:3000/api/health`

## 注意事项
1. **防火墙**：确保阿里云安全组已开放 3000 端口
2. **域名**：如需自定义域名，配置 Nginx 反向代理
3. **HTTPS**：建议使用 Let's Encrypt 免费证书

## 故障排查
```bash
# 查看日志
pm2 logs ai-prototype

# 重启服务
pm2 restart ai-prototype

# 检查端口
netstat -tlnp | grep 3000
```
